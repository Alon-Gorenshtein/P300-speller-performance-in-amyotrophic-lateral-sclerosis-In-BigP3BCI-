# Robustness matrix

| Analysis | Purpose | Status |
|---|---|---|
| Leave-one-study-out calibration AUC | Primary external validation; prevents source-study leakage | Primary |
| Pz-amplitude model | Tests whether a simple single-channel ERP amplitude carries the same transferable information | Secondary |
| Calibration AUC plus ALSFRS-R | Tests incremental information from functional score; not causal or prognostic | Exploratory |
| Within-study leave-one-participant-out | Tests whether the primary relationship persists when each study-scoped participant is unseen | Sensitivity |
| Trial exclusion ledger | Confirms artificial feedback and non-feedback phases are not counted as BCI classifier outcomes | Sensitivity |

Cross-study identity cannot be resolved from the public de-identified archive. Therefore, all primary validation is study-held-out and no cross-study participant linkage is inferred.
