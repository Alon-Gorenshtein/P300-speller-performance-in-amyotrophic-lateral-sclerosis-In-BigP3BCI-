# Submission package

This package supports a manuscript on calibration EEG and online P300-speller performance in ALS using BigP3BCI version 1.0.0.

## Included materials

- `manuscript/manuscript.md`: full manuscript with tables, figure legends, declarations, and AMA references.
- `manuscript/references_source.tex`: citation-verifier input.
- `manuscript/references_source_AMA.txt`: verified AMA bibliography after the citation workflow runs.
- `manuscript/references_source_for_zotero.bib`: Zotero-importable verified bibliography after the citation workflow runs.
- `supplementary/supplement.md`: reproducibility supplement.
- `output/final/`: frozen analysis records, validation metrics, exclusions, and publication figures.
- `docs/`: provenance, feature, outcome, and statistical-analysis specifications.

## Scope

The work is an external validation analysis across historical public ALS P300-speller source studies. It is not an acute GBS, ICU, covert-consciousness, prospective, causal, or clinical-outcome study. Study-scoped IDs must not be described as unique persons across source studies.

## Intended first journal

The analysis is best positioned initially as a methods-oriented clinical neurotechnology manuscript for *Journal of Neural Engineering* or *Clinical Neurophysiology*. Its evidence base does not support a claim to a broad clinical-neurology journal as a prospective clinical study.
